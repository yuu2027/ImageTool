# staticとは
１．関数の中の local 変数に付ける
普通のローカル変数は、関数が呼ばれるたびに作られて、関数が終わると消える
しかし static を付けると、最初の1回だけ作られ、その後も値を保持

２．クラスのメンバに付ける
普通のメンバ変数は、オブジェクトごとに1つずつ持つ
一方 static メンバ変数は、クラス全体で1つだけ共有

３．クラスのメンバ関数に付ける
static メンバ関数は、オブジェクトを作らなくても呼べる関数

４．ファイル内の変数や関数に付ける
この場合の static は、その変数や関数をその.cppファイル内だけで使えるようにするという意味

# unordered_set
値を重複なしで保存するための入れ物．
・同じ値を2回入れられない
・高速に「その値があるか」を調べやすい
１．insert()
重複を許さず値を挿入
２．count()
その値があれば1，なければ0を返す
